the existing Codex 5.3 Spark semantic author now meets every frozen gate before

## Acceptance Criteria

- All ten targets are accounted for once, with no substitution or recovery
  provider.
- Purpose accuracy is at least 0.85; evidence-supported claims at least 0.95;
  schema-valid proposals exactly 1.0; reviewer edit burden at most 0.25.

  improves.
- False novelty, duplicate experimental intent IDs, and duplicate semantic
  stems are all zero.
- P55-T10H is marked unblocked only when every frozen gate passes.
- No raw prompts, raw responses, hidden reasoning, credentials, or
  machine-local paths enter durable evidence.
- No repository code, package manager, acceptance, materialization,
  canonicalization, registry mutation, or publication path runs.
