# P55-T10G3 Repeat Ten-Repository Semantic Calibration

## Objective

Repeat the exact P55-T10G calibration after P55-T10G1 and P55-T10G2 and decide
whether the frozen gates now authorize P55-T10H.

## Frozen Scope

- Reuse P55-T10G plan SHA-256
  `376001a3ea1053afb5908bf1b7cb8125b95da4eebf2d76a6422e733f06844a11`.
- Run the same ordered targets: Axios, n8n, Firecrawl, Bitcoin, Excalidraw,
  Codex, claude-mem, Angular, Electron, and freeCodeCamp.
- Use Codex 5.3 Spark through the existing `codex exec` adapter.
- Reuse the immutable P55-T10C baseline, source revisions, candidate packets,
  P55-T5 thresholds, denominators, supervisor rubric, and execution budgets.

## Deliverables

- Ten digest-bound terminal records produced by the existing resumable runner.
- A new digest-bound supervisor purpose assessment using the unchanged rubric.
- A deterministic G3 report and portable proposal-record archive.
- Exact comparison with P55-T10G and the immutable P55-T10C baseline.
- Tests, documentation, validation, archive, and structured review evidence.

## Acceptance Criteria

- All ten targets are accounted for once with no target substitution.
- Purpose accuracy is at least 0.85, evidence support at least 0.95,
  schema-valid rate exactly 1.0, and reviewer edit burden at most 0.25.
- Generic intent reuse is below baseline and at least one repaired generic case
  improves.
- False novelty, duplicate experimental IDs, and duplicate semantic stems are
  all zero.
- P55-T10H is unblocked only if every frozen gate passes.
- No raw prompts, raw responses, hidden reasoning, credentials, or machine-local
  paths enter durable evidence.
- No repository code, package manager, acceptance, materialization,
  canonicalization, registry mutation, or publication path runs.

## Dependencies

- P55-T10G frozen plan and baseline comparison logic.
- P55-T10G1 Outcome-Level Purpose Anchors.
- P55-T10G2 Validation-Aware Semantic Repair.

## Non-Goals

- Changing targets, thresholds, denominators, rubric, provider, or budgets.
- Running the 46-repository P55-T10H scope.
- Treating provider output as accepted or canonical.
