# Semantic Author Input Pack

P55-T3 creates a deterministic bounded evidence pack for the P55-T2 semantic
author request. It contains only allowlisted candidate artifacts, supplied
documentation as inert untrusted evidence, and observed intent records with
paths and SHA-256 digests.

No model, repository code, package manager, adapter, reviewer action, or
materializer runs. Unsafe paths, symlinks, stale catalogs, duplicate intents,
and budget exhaustion fail closed.

<doc:AISemanticAuthorSchemas> defines the request and observed-intent records.
